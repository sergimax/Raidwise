Raidwise / Design exploration / 01

Фон, который собирает интерфейс

Восемнадцать направлений для фона приложения, хедера, подложек панелей и рабочих блоков. Один макет и одинаковые данные помогают сравнить именно поверхности. Это концепты, а не точная копия текущего интерфейса.

I–R: новые исследования на основе E

A · Тёплый матовый

Тёплый фон без узора, непрозрачный хедер, чуть приподнятая подложка и чистые рабочие блоки. Акцент остаётся оранжевым. Самый спокойный вариант для долгой работы с таблицами.
