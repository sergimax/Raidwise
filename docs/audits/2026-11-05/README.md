# Аудит Raidwise Web — 5 ноября 2026

Исходный аудит проведён на версии **2.11.0**, коммит `27955e2d658cfeef6071ab19ad4254f258f4b478`. Выводы и цифры ниже относятся к исходному состоянию. Результаты внедрения семи этапов и проверки версии **2.12.0** приведены в [повторной проверке](recheck-2026-11-06.md).

## Вывод

Приложение собирается, имеет развитую систему тестов и разумное разделение UI, доменного состояния и persistence.
Главный риск — сохранность единственной локальной копии данных: неполная проверка входного JSON, перезапись при неудачной загрузке, окно потери последних изменений и отсутствие разрешения конфликтов вкладок.
Следующий приоритет — восстановление после ошибок загрузки данных.
Переписывать приложение или вводить новый глобальный state manager по результатам аудита не требуется.

Найдено **13 пунктов**: 4 с приоритетом P1, 7 с P2, 2 с P3.
Это не 13 воспроизведённых пользовательских инцидентов: способ подтверждения указан у каждого пункта.
Отдельные архитектурные риски и технический долг не включены в это число.

## Что проверено

- Bootstrap, маршрутизация, провайдеры и владение состоянием.
- Tracker/BiS: загрузка, миграции, запись, обработка ошибок, обновление сущностей.
- WowSims import, gear/BiS hints, фильтры и soft reserve: контракты, тесты, критические места вычислений.
- Ленивая загрузка справочников и внешних tooltip-скриптов.
- EN/RU, доступность отдельных контролов, clipboard и браузерные smoke-сценарии.
- TypeScript, ESLint, тесты, покрытие, production bundle, CI и advisory зависимостей.

## Границы заключения

Это комплексный аудит локального исходного кода и сборки, а не гарантия отсутствия ошибок.
Production-сайт, HTTP-заголовки сервера, реальные пользовательские данные и live CI не проверялись.
Браузерные проверки автоматические; полного ручного обхода всех экранов, screen reader, Firefox/Safari и mobile devices не было.
Игровые справочники и математическая модель подсказок не сверялись с внешним источником для каждого предмета/специализации.
Нагрузочный профиль и новые Lighthouse-замеры не снимались; старые badges не считаются текущими измерениями.
